# CodeAlpha Internship Tasks

This repository contains three Java projects developed
for the CodeAlpha internship.

## Task 1: Student Grade Tracker

- Accepts student names and marks.
- Stores data using arrays.
- Calculates average, highest, and lowest marks.
- Displays a student grade report.

## Task 2: Stock Trading Platform

- Displays simulated stock market data.
- Supports buying and selling shares.
- Tracks available cash and stock holdings.
- Calculates total portfolio value.
- Uses object-oriented programming.

## Task 3: Artificial Intelligence Chatbot

- Provides interactive text-based communication.
- Recognizes common questions using keywords.
- Uses rule-based responses.
- Demonstrates basic text processing.

## Technologies Used

- Java
- Object-Oriented Programming
- Arrays
- Collections
- Conditional Statements
- Loops

## How to Run

Open the required Java file in Visual Studio Code
and click Run Java.

Each task is a separate program.
